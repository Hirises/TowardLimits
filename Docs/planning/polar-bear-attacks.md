# 극곰 공격 패턴

[인덱스](../INDEX.md)

## 적 역할과 배치

일반 극곰(`PolarBear`)은 기본 1라인 눈덩이 굴리기를 사용하고, 대장극곰(`CaptainPolarBear`)은 2라인 눈덩이 굴리기와 칸 지정 낙하 눈덩이 던지기를 함께 사용한다. 대장극곰의 이미지는 `Captine_PolarBear`를 사용한다. 이동·공격 시작 조건은 각각의 EnemyData에서 조정한다.

기존 보스 웨이브 중 마지막 스테이지의 `BossWave4`(스테이지 인덱스 4)에 대장극곰을 배치한다. `BossWave0`~`BossWave3`은 일반 극곰을 유지한다. 두 적 모두 보스 경고 표시를 사용한다.

## 일반 극곰의 굴리는 눈덩이

일반 극곰은 `enemy_polarbear_snowballType`으로 소환할 눈덩이를 선택하며 기본값은 1라인 `Snowball`(5)이다. 2라인 `Snowball2Line`(7)은 기존 눈덩이와 동일한 스프라이트·마테리얼을 사용하는 별도 프리팹과 EnemyData이며 시각 크기와 충돌 범위를 2배로 설정한다. 나머지 초기 능력치는 기존 눈덩이와 동일하다.

2라인 눈덩이는 인접한 두 라인의 중간에서 생성한다. 일반 극곰은 전장 안의 인접 라인 쌍 중 하나를 동일 확률로 선택한다. 기존 1라인 눈덩이는 각 라인의 중심에서 생성한다. 눈덩이는 기존과 동일하게 첫 유닛 충돌 시 피해를 주고 소멸한다.

선택 필드는 일반 극곰 EnemyData와 `OverrideData/Enemy/PolarBear.json`에서 설정한다. 눈덩이별 체력·피해·속도는 각 EnemyData와 해당 이름의 Enemy JSON에서 설정한다. 필드 형식은 [Override Data 가이드](../OverrideData_Format.md#3-enemy-data)를 참조한다.

## 대장 극곰의 두 공격

대장 극곰은 일반 원거리 공격 속도 `attackSpeed`에 따라 2라인 `Snowball2Line`을 굴린다. 소환 위치와 눈덩이별 능력치 설정은 일반 극곰과 같은 규칙을 따른다.

던지기는 `enemy_captainpolarbear_throwInterval`초마다 독립 실행하며 초기 주기는 1초다. 공격 시작 후 한 주기 뒤 첫 던지기를 실행한다. 피해는 `enemy_captainpolarbear_throwDamage`(초기값 50), 동시 생성 수는 `enemy_captainpolarbear_throwCount`(초기값 1)로 설정한다. 피해는 일반 원거리 피해와 스테이지 증가량에 독립된 고정값이다. 주기가 0 이하이면 던지기를 대기하며 생성 수가 0 이하이면 눈덩이를 생성하지 않는다.

두 공격의 시작·중단 조건은 `rangeAttack`·`stopAtMiddle`·`attackWhileMoving`을 공유한다. `attackSpeed`가 0 이하일 때도 던지기는 설정된 주기를 따른다. 전용 필드는 대장 극곰 EnemyData와 `OverrideData/Enemy/CaptainPolarBear.json`에서 설정한다.

## 낙하 눈덩이

대장극곰은 던지기 주기마다 설정된 수의 눈덩이를 동시에 생성한다. 빈 칸을 포함한 전체 배치 칸에서 서로 다른 칸을 무작위로 지정한다. 동시 생성 수가 전체 칸 수를 초과하면 전체 칸 수만큼 생성한다. 각 주기에는 전체 칸에서 새로 추첨하므로 이전 주기에서 지정한 칸도 다시 선택할 수 있다. 지정 칸 상공에서 눈덩이가 떨어지고 바닥의 그림자가 점점 커진다. 낙하 시간은 게임 시간 기준 1초이며 던지기 주기와 함께 배속, 드래그 중 감속, 일시정지를 따른다.

지정한 칸은 낙하가 끝날 때까지 고정한다. 착지 순간 그 칸의 현재 유닛에게 한 번 피해를 준다. 재배치를 완료하면 회피할 수 있고, 교환으로 들어온 유닛은 피해를 받는다. 빈 칸에는 착지 연출을 재생한다.

낙하와 착지 연출이 진행 중이어도 다음 던지기 주기에는 새 눈덩이를 생성한다. 착지 시 눈덩이가 파편으로 흩어지고 그림자가 사라진다. 대장극곰 사망·파괴와 전투 종료 시 진행 중인 낙하 공격을 모두 취소한다.

낙하 공격 프리팹은 대장극곰 프리팹에서 설정한다. 낙하 시간·높이·그림자 시작 배율·파편 연출은 SnowballStrike 프리팹에서 설정한다. 실제 전투 칸 크기에 맞춘 초기 눈덩이·최종 그림자 지름은 1.2다.
