# 극곰 공격 패턴

[인덱스](../INDEX.md)

## 적 역할과 배치

2026-10-13 사용자 확정: 일반 극곰(`PolarBear`)은 기존 라인 눈덩이 굴리기 공격을 사용하고, 대장극곰(`CaptainPolarBear`)은 칸 지정 낙하 눈덩이 공격을 사용한다. 대장극곰의 이미지는 `Captine_PolarBear`를 사용한다. 초기 능력치와 이동·공격 시작 조건은 기존 극곰과 동일하며 각각의 EnemyData에서 조정한다.

기존 보스 웨이브 중 마지막 스테이지의 `BossWave4`(스테이지 인덱스 4)에 대장극곰을 배치한다. `BossWave0`~`BossWave3`은 일반 극곰을 유지한다. 두 적 모두 보스 경고 표시를 사용한다.

## 낙하 눈덩이

대장극곰은 공격 주기마다 전체 배치 칸 중 하나를 동일 확률로 지정하며 빈 칸도 포함한다. 지정 칸 상공에서 눈덩이가 떨어지고 바닥의 그림자가 점점 커진다. 낙하 시간은 게임 시간 기준 1초이며 배속, 드래그 중 감속, 일시정지를 따른다.

지정한 칸은 낙하가 끝날 때까지 고정한다. 착지 순간 그 칸의 현재 유닛에게 한 번 피해를 준다. 재배치를 완료하면 회피할 수 있고, 교환으로 들어온 유닛은 피해를 받는다. 빈 칸에는 착지 연출을 재생한다. 피해량은 대장극곰의 원거리 피해와 스테이지 증가량을 따른다.

낙하와 착지 연출이 진행 중이면 다음 공격 주기의 중복 생성을 억제한다. 초기 공격 속도는 초당 1회이며, 진행 중인 연출과 겹치는 주기는 건너뛴다. 착지 시 눈덩이가 파편으로 흩어지고 그림자가 사라진다. 대장극곰 사망·파괴와 전투 종료 시 진행 중인 공격을 취소한다.

낙하 공격 프리팹은 대장극곰 프리팹에서, 공격 속도는 대장극곰 EnemyData에서 설정한다. 낙하 시간·높이·그림자 시작 배율·파편 연출은 SnowballStrike 프리팹에서 설정한다. 실제 전투 칸 크기에 맞춘 초기 눈덩이·최종 그림자 지름은 1.2다.
