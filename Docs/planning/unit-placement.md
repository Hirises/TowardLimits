# 유닛 드래그 배치

## UX 합의

2026-10-03 사용자 확정: 드래그 대상 선택은 holdMotion 이미지 사각형의 하단 중앙을 기준으로 화면 좌표에서 수행한다. 이미지별 발 오프셋은 공통 하단 중앙을 사용한다.

기준점이 슬롯의 화면상 바닥 영역 안에 있으면 해당 슬롯을 즉시 선택한다. 그 밖에서는 슬롯 중심과의 화면상 거리로 대상을 정한다. 대상 선택과 배치 가능 여부는 분리하며, 점유 상태와 DT 잔량에 관계없이 같은 슬롯을 가리킨다.

근접 스냅은 최대 거리와 대상 전환 여유값을 사용한다. 두 값은 Canvas 기준 단위로 조절하며 초기값은 각각 120, 12다. 직접 슬롯 위에 올라가면 즉시 전환한다. 최대 거리 밖에서는 대상을 해제한다.

미리보기는 배치 가능을 초록색, 교환 가능을 청록색, 배치 불가를 빨간색으로 표시한다. 미리보기와 드롭은 같은 대상 선택 결과를 사용한다. 배치 단계의 필드 유닛 회수는 마우스가 인벤토리 영역에 들어왔을 때 우선 처리한다.
