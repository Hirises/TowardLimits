## 문서 동기화 지침

- Override Data 문서와 관련 Notion을 수정할 때 JSON 필드는 연관된 역할별로 묶어 정렬한다. 예를 들어 적 데이터는 기본 데이터, 원거리 공격용 데이터, 레벨업 데이터처럼 구분한다. 2026-10-14 사용자의 지속 요청이며, 다음 문서 수정부터 적용한다.

- 사용자의 “index에 저장해서 기억” 요청은 `Docs/INDEX.md`와 연결 문서 체계에 지속 기록하라는 의미다. 인덱스에는 간단한 프로젝트 정의와 문서 참조를 유지하고, 상세 지침은 적절한 연결 문서에 기록한다. 2026-10-03 사용자 확인이다.

- Override Data 가이드는 기획자의 값 수정·밸런싱에 필요한 정보로 간결하게 작성한다. 필드 이름으로 설명 가능한 내용은 표에만 적고, 초기값은 JSON 예시로 표현한다. 표·예제 아래에 설명을 반복하거나 구현 동작 원리·초기화 이력을 덧붙이지 않는다. 계산식·설정 제약 등 밸런싱에 영향을 주는 정보만 유지한다. 2026-10-03 사용자의 지속 요청이다.

- Override Data의 필드명·타입·계산식·예제는 실제 직렬화 모델과 항상 정확히 일치시킨다. 필드 추가·이름 변경·삭제·동작 변경을 수행하는 같은 작업에서 기본 에셋, 관련 JSON 예제, 로컬 가이드와 Notion 가이드를 함께 갱신하고 구현과 대조해 검증한다. 부분 오버라이드 JSON은 필요한 필드만 포함할 수 있으며, 생략 필드의 병합 동작도 정확히 안내한다. 2026-10-03 사용자의 지속 요청이다.

- JSON Override Data 관련 변경 시 로컬 [Override Data 가이드](../OverrideData_Format.md)와 프로젝트 Notion의 [외부 데이터 수정 방법](https://app.notion.com/p/32e6fe07699b80ea9a3fd2f47ae44d41) 페이지를 함께 업데이트한다. 필드명·타입·동작·예제 및 호환성 안내를 실제 구현과 일치시킨다. 사용자 요청에 따른 지속 지침이며, Notion 페이지를 수정할 수 없는 경우 미반영 사항을 사용자에게 알린다.

## 구현 착수 시 확인할 맥락

- **함수 탄환 색상:** 일반 공격과 스킬 탄환은 발사 시점의 `UnitModel.unitColor` RGBA 값을 적용한다. 발사 이후 해당 탄환은 발사 시점의 색상을 유지한다. 2026-10-28 사용자 확정 요청이다.

- **적 일반 탄환 속도 합의:** `bulletSpeed`에 발사 순간의 실제 적 이동 속도를 더하고 발사 후 유지한다. 정지 중 가산값은 0이며, 이동 중 가산값은 스테이지 증가량을 포함한다. 탄환 자체 속도는 기본 에셋의 기존 `speed`로 초기화하고 별도로 오버라이드한다. 극곰의 눈덩이 소환은 적용 범위에서 제외한다. 2026-10-03 사용자 확정 요청이다.

- **적 이동·공격 합의:** `rangeAttack`은 주기 공격 활성화, `stopAtMiddle`은 중앙선 정지, `attackWhileMoving`은 소환 직후부터 이동·정지와 관계없이 공격하는 설정이다. 중앙선 정지는 적 콜라이더의 좌우 범위에 라인 중심이 포함된 모든 라인을 검사하며, 하나라도 유닛이 있으면 적용하고 해당 라인이 전부 비면 전진을 재개한다. 정지 중 공격 여부와 탄환 발사 시 이동 속도 계산도 같은 검사 범위를 사용한다. 여러 라인에 걸친 극곰에도 적용하는 것은 2026-10-08 사용자 확정 요청이다. 이동 중 공격은 빈 라인에서도 소환 즉시 첫 발사 후 반복하고, 정지 전용 공격은 정지 후 한 주기 뒤 첫 발사한다. 노란 적은 중앙선 정지 없이 이동 중 공격하고, 극곰은 중앙선 정지 후 공격한다. 충돌 피해는 별도로 유지한다. 세부 데이터 형식은 [Override Data 가이드](../OverrideData_Format.md#3-enemy-data)를 참조한다.
- **적 데미지 명칭 합의:** 2026-10-03 사용자 요청에 따라 충돌 공격은 `damage`·`damage_add`, 원거리 투사체 공격은 `rangeDamage`·`rangeDamage_add`를 사용한다. 양쪽 모두 기본값 + 스테이지당 증가량 × 현재 스테이지로 계산한다. 회의의 `attackDamage` 제안 이후 확정된 명칭은 `rangeDamage`다.
- **이차함수 스킬:** 계수와 관계없이 `X2_Bullet` 스프라이트를 사용하는 특수 탄환을 한 번 발사한다. 중앙과 좌우 인접 라인의 판정을 공유하며, 중앙 판정이 진행 방향으로 돌출된다. 첫 적 명중 시 피해를 한 번 적용하고 전체 탄환이 소멸한다. 가장자리에서는 전장 안의 판정만 활성화한다. 피해량 `unit_x2_skillDamage`와 속도 `unit_x2_skillBulletSpeed`는 계수·일반 공격·버프와 독립적으로 설정하며, 사거리는 `attackRange`, 피해 유형은 `attackType`을 사용한다. 일반 공격은 기존 3라인 발사를 유지한다. 2026-10-13 사용자 확정 요청이다. 설정은 [Override Data 가이드](../OverrideData_Format.md#2-unit-data)를 참조한다.
- **대장 극곰 패턴:** 칸 지정 낙하 눈덩이와 커지는 그림자 예고는 2026-10-07 확정·구현되었다. 상세 사양은 [극곰 공격 패턴](polar-bear-attacks.md)을 참조한다. X자 공격과 포효 전체 공격은 아이디어 후보이며 확정 사양은 아니다.
- **기획 확인 범위:** 상위 기획 페이지와 9/30 Slack 대화가 이 문서의 근거다. 상세 하위 기획은 관련 작업에 착수할 때 확인한다.
