# 컷씬 편집기

Project 창에서 `CutSceneData` 에셋을 선택하면 Inspector에 UI Toolkit 기반 카드형 편집기가 표시된다.

## 편집

- 대사 입력란은 내용과 줄바꿈에 따라 높이가 늘어나고, 최대 높이에서는 내부 스크롤을 제공한다.
- 카드의 `≡` 핸들을 드래그하고 강조된 삽입 위치에서 놓으면 순서를 변경한다. Escape 키는 드래그를 취소한다.
- 목록의 처음, 액션 사이, 마지막의 `+` 메뉴에서 빈 액션을 추가한다. 앞선 액션이 있으면 이전 화자 유지와 이전 액션 복제도 선택할 수 있다.
- 이전 화자 유지는 삽입 위치 직전까지 누적된 닉네임·이미지·좌우 위치를 새 대사에 적용한다. 액션 복제는 함수 호출을 포함한 해당 액션의 모든 필드를 복사한다.
- 복제·삭제·삽입·순서 변경과 필드 편집은 Unity Undo/Redo를 사용한다.
- 검색은 닉네임, 대사, 함수 대상 및 메서드 이름을 대상으로 한다. 검색 결과는 원래 순번을 표시하며, 전체 순서를 확인할 수 있는 빈 검색 상태에서 삽입과 드래그를 제공한다.
- 카드 맨 위의 `Type`에서 `대사`, `함수 실행`, `대기`를 선택한다. 선택한 유형에 필요한 설정만 표시한다.
- 펼치기·접기 버튼은 카드 설정 영역을 일괄 제어한다. 미리보기 패널은 별도로 접을 수 있다.

## 미리보기

카드를 선택하거나 이전·다음 버튼을 누르면 첫 액션부터 선택한 액션까지 누적된 표시 상태를 보여준다. 대사 유형은 해당 액션의 닉네임·대사·이미지·좌우 위치를 적용한다. 빈 닉네임은 표시를 비우고, 이미지가 `None`이면 좌우 이미지를 모두 지운다. 함수 실행과 대기 유형은 현재 대화 화면을 유지한다. 이 규칙은 실제 컷씬 재생에도 적용된다.

미리보기는 데이터의 이미지·닉네임·대사를 표시한다. 함수에 의한 외부 상태 변경과 씬의 실제 UI 배치는 게임 재생으로 확인한다.

## 함수 호출과 대기

`함수 실행` 유형에서 대상에는 현재 씬의 활성 GameObject 이름, 메서드에는 실행할 함수 이름을 입력한다. 재생기는 기존 `GameObject.Find` / `SendMessage` 방식으로 실행하고 다음 액션으로 진행한다. 대상이나 메서드가 비어 있으면 설정 경고를 표시한다. 메서드 이름은 Enter 또는 포커스 이동 시 반영된다.

`대기` 유형에서 대기 중 화면을 `화면 유지` 또는 `화면 숨기기`로 선택한다. 각각 기존 `WaitUntil`, `WaitUntilAndHide` 메서드에 대응한다. 대상에는 `CutsceneManager` 컴포넌트가 붙은 GameObject 이름을 입력한다. 대기 중 게임 시간은 다시 흐르며, 외부에서 `Continue()`를 호출하면 재개한다. 미리보기에서는 함수 호출 없이 표시 상태만 계산한다.

## 데이터 호환성

편집기는 기존 `CutSceneData`와 `CutSceneAction`의 필드명, 자료형 및 직렬화 구조를 사용한다. 유형은 기존 `callFunction`과 `method`에서 판별하며, 유형 전환도 이 필드를 Undo 가능한 방식으로 편집한다. 에셋 마이그레이션 없이 기존 SO를 편집하며, 새 빈 액션은 모든 필드를 명시적으로 초기화한다.

기존 `clearSprite` 값은 이전 에셋의 표시 결과를 보존하기 위한 호환 데이터로 유지한다. 기존 이미지 지우기 액션은 편집기에서 이미지 `None`으로 표시하며, 이미지를 새로 지정하면 호환 값을 해제하고 지정한 이미지를 사용한다. 편집기는 이미지 참조로 표시 여부를 설정한다. 함수 실행·대기 액션은 기존 화자·대사 필드를 보관하므로 대사 유형으로 다시 전환하여 편집할 수 있다.
